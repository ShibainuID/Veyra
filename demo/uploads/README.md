# Demo upload kit

Every file a presenter uploads during the VEYRA demo, in the order the story uses them. Reset first:
**Demo reset → post-enrollment** (Sari, `animal-demo-001`, is enrolled and not insured) or **fresh** to enroll her live.
All footage is AI-generated (Google Veo; `demo/media/veo/VEO_PROMPTS.md`), not a real farm.

| File | Where it goes | What it shows |
| --- | --- | --- |
| `video_hp.mp4` | **Enroll → Upload a video** (or the built-in **Use the phone enrollment video**, which is the same clip) | One guided phone video: muzzle, teeth, body. Enrollment extracts the frames, proposes Sari, and waits for a person to confirm identity. |
| `sari-ownership-sample.pdf` | **Passport (Sari) → Documents → Ownership → Choose file and upload** | A clearly marked SAMPLE ownership certificate (fictional). It becomes Sari's ownership reference, so **Mortality + Theft** moves from "needs review" to eligible on the insurance comparison. |
| `09_hp_muzzle.png` | **Claim → Identity check → Upload muzzle photo or video** | A muzzle close-up of the enrolled cow: the re-scan **matches** and the death claim can proceed. |
| `05_muzzle_closeup.jpg` | **Claim → Identity check → Upload muzzle photo or video** | A different cow's muzzle: the re-scan is a **mismatch** and blocks submission (the anti-fraud guard). |
| `incident-photo.jpg` (optional) | **Passport → Documents → Other** (or wherever the agent's claim flow asks for an incident photo) | A still at 4 s of the Veo barn CCTV clip (`demo/media/veo/video_cctv.mp4`), as supporting incident evidence. |

`sari-ownership-sample.pdf` is generated by `make_ownership_sample.py`
(`uv run --no-project --with fpdf2==2.8.3 python demo/uploads/make_ownership_sample.py`). Every name in it is the
demo's own fiction (Wahyu Farms, W. Santoso, Sari); it carries a "SAMPLE — demo document" watermark and certifies
nothing.

`incident-photo.jpg` was extracted with
`ffmpeg -ss 4 -i demo/media/veo/video_cctv.mp4 -frames:v 1 -vf scale=1280:-2 -q:v 4 demo/uploads/incident-photo.jpg`.

The MP4 and the PNG are Git LFS files (`.gitattributes`); run `git lfs pull` if they are small text pointers.
